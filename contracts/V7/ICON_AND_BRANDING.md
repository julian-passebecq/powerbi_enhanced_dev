# PbiBench Icon / Branding Brief

## Requirement

The current application has no proper window/taskbar icon.

Create an original icon.

## Concept

A compact semantic-model / engineering mark:

Option A:
- stylized `P` and `B`
- one small connected-node motif

Option B:
- three connected model nodes inside a compact square/hex frame
- subtle `PB` negative-space suggestion

## Palette

Use PbiBench's own palette:
- deep navy: `#173C52`
- ink: `#15232D`
- accent yellow: `#E7BE24`
- white: `#FFFFFF`

Do not copy:
- Power BI logo
- Fabric logo
- Tabular Editor logo
- DAX Studio logo

## Technical output

Generate:
- source SVG
- `.ico` containing 16, 24, 32, 48, 64, 128, 256
- optional PNG preview

Wire:
- executable `ApplicationIcon`
- WPF Window `Icon`
- taskbar
- future installer shortcut

Verify actual taskbar rendering on Windows.
