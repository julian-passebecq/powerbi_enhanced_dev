## Caution / isolated use

### DAX Studio
- Microsoft Reciprocal License (Ms-RL).
- do not merge files into permissive PbiBench core by default.
- use as separate process/reference, or isolate reused files under Ms-RL obligations.

### DAX Studio Controls
- no explicit license found in uploaded snapshot.
- no copying until provenance/license is confirmed.

### TabularEditor BestPracticeRules
- uploaded snapshot contains no clear license file.
- use as private reference; do not redistribute/copy rule corpus into product until license is verified.
- PbiBench can ship its own independently written rules.

### SQLBI downloaded PBIX sample
- user lawfully supplied the file, but no redistribution license was established.
- use as private local fixture only.
- do not embed in public releases.

### pbi-tools
- AGPL-3.0.
- external benchmark/tool only unless project licensing strategy deliberately accepts AGPL.
