# TE3-like capability priority - independent implementation

Public TE3 documentation is a benchmark for user needs, not implementation source.

## Build now / realistic

### Tier 1
- modern model explorer
- property editor
- dependency graph
- model diagram
- DAX expression editor
- lightweight DAX query tabs
- table data preview
- multi-measure DAX script document
- perspectives editor
- translations editor
- typed bulk actions
- C# macro compatibility for trusted TE2 scripts
- VertiPaq/VPAX adapter
- Git/PBIP workspace

These are achievable with public TOM/ADOMD/TMDL/PBIP interfaces and TE2's MIT foundation.

## Build later / harder but worthwhile

### Tier 2
- live model <-> PBIP disk synchronization
- schema comparison/update assistant
- refresh queue and progress
- command/action recorder
- advanced DAX refactor/code actions
- pivot/matrix test surface
- Direct Lake-specific diagnostics
- semantic model migration/bridge tools.

## Do not promise early

### Tier 3
- true line-by-line DAX debugger with full live context inspection
- exact TE3 Workspace Mode behavior
- exact TE3 DAX parser/editor implementation
- exact DAX Optimizer integration behavior.

Instead build an original **DAX Inspector/Explain**:
- variables/dependencies
- filter-context test queries
- query plan/timing handoff to DAX Studio
- call/dependency graph
- generated intermediate DAX queries.

The goal is workflow capability, not product cloning.
