# VizForge Custom Visual Studio

## Product benchmark

PBIVizEdit demonstrates market demand for:
- a visual gallery,
- modifying templates,
- uploading sample data,
- mapping data fields,
- editing visual attributes,
- exporting `.pbiviz`.

PbiBench should build an original developer-oriented system around the same general problem.

## Visual creation pipeline

```text
Analytical intent
 -> choose native or custom
 -> VizSpec
 -> data roles
 -> primitive layers
 -> format properties
 -> interactions/tooltips
 -> D3 preview
 -> accessibility/performance QA
 -> native PBIR OR generated pbiviz
```

## Reference implementations

The supplied Microsoft ForceGraph and MultiKPI repositories are MIT and useful for learning:
- D3 integration
- capabilities.json
- data roles
- settings/formatting
- selection/interactions
- tooltips
- visual API packaging.

Do not copy their brand assets into original templates.

## Export

1. Native PBIR visual if possible.
2. Otherwise generate a Visual Tools project:
   - package.json
   - pbiviz.json
   - capabilities.json
   - formatting model
   - TypeScript renderer
   - tests
   - assets
3. run `pbiviz package`.
4. test in controlled report fixture.

## Security

Custom visuals are executable code.

PbiBench must show:
- source/provenance
- network privileges/capabilities
- external service dependencies
- certificate/AppSource status if applicable
- package hash.
