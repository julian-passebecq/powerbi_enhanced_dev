# VS Code companion role

Do not make VS Code the primary PbiBench UX.

Use it as a precision text/Git companion.

## Good VS Code tasks
- raw TMDL editing
- PBIR JSON inspection
- `.dax` query files
- `.tmdl` script files
- merge conflicts
- repository search
- Codex-driven code changes
- custom visual TypeScript development.

## PbiBench integration

Buttons:
- Open project in VS Code
- Open current TMDL object
- Open current PBIR visual/page file
- Open DAXQueries folder
- Open Git conflict file.

PbiBench remains the visual/semantic guide and validation authority.
