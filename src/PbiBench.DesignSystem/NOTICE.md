# PbiBench design system 1.0

The 14 vector paths in `PbiBenchTheme.cs` are original PbiBench artwork, created for this project on 2026-09-05 and distributed under the adjacent MIT `LICENSE`. The source file is the complete local icon inventory. There are no upstream icon/font files, Data Goblin assets or copied application code. Paths render directly as WPF geometry and scale with Windows DPI.

Shared tokens: neutral background #F5F6F8, white surface, border #DDE1E6, text #20252D, secondary #626B78, accent #315DA8. Segoe UI; spacing 4/8/12/16/24/32; 32px minimum buttons. Child modules reference this UI-only assembly within their own runtime folders.
